# projectbrief — 무엇을, 왜 만드나 (거의 안 바뀜)

출처: 「AI P-실무프로젝트(캡스톤디자인) 과제 계획서」 3차본, 노션 「역할분담」. 계획서 원본은 저장소에 없다 (개인정보 포함).

**고령자를 위한 개인화 AI 대화·인지 놀이 서비스**
Personalized AI Conversation and Cognitive Activity Service for Older Adults (PACCA)
- 과목: AI P-실무프로젝트(캡스톤디자인), SW4 분반 3조 · 학생 자율 주제 · 크롤링/자체생성 데이터
- 수행 기간: **2026.9.1 ~ 2026.12.21**

## 왜
- 독거 고령자 정서적 교류 부족 + 경도인지장애 증가. 외로움과 인지 저하는 서로 관련 있다.
- 기존 서비스(클로바 케어콜, 효돌, AI 가족안부전화)는 안부 확인·돌봄 중심이거나 전용 기기가 필요하다.
- 그래서: **전용 기기 없이 스마트폰에서**, **어르신이 원할 때 직접** 대화하고 놀이에 참여하는 AI 친구.

## 최종 목표 4개
1. **고령자 주도형 AI 일상 대화**: Android 앱, 음성 대화, 고령자 친화 화면
2. **개인 기억 기반 맞춤 대화**: 대화에서 관심사·선호·경험을 추출·저장하고 이후 대화에 활용
3. **자율 참여 맞춤 인지 놀이**: 회상 놀이 + 관심사 퀴즈. 원할 때만, 대화와 자연스럽게 연결
4. **동의 기반 보호자 연동**: 어르신이 고른 항목의 일상 요약·놀이 참여 정보만 보호자에게

## 정량 목표 (6장 평가에서 검증)
| 항목 | 목표 |
|---|---|
| 핵심 기능 구현 | 대화·개인화·인지 놀이·보호자 연동 4개 |
| 기억 추출 정확도 | 80% 이상 |
| 허위 기억 발생률 | 5% 이하 |
| 기억 활용 응답 선호율 | 기본 LLM 대비 평가자 선호 60% 이상 |
| 퀴즈 정답 판정 정확도 | 90% 이상 |
| (측정만) | API 응답 시간, 비용 |
- 평가 데이터: 정답·평가 기준을 미리 정한 **가상 테스트 사례 100~120개** (실제 고령자 정보 사용 안 함)
- Baseline: 같은 LLM에 현재 대화만 준 경우 vs 관련 기억을 추가로 준 경우

## 하지 않는 것
- 의학적 판단 (보호자 화면에도 없음)
- 대규모 모델 학습 (기존 LLM API 사용)
- 보호자에게 대화 원문·기억 보여 주기
